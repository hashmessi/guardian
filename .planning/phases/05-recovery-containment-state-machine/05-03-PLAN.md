# Phase 5 Plan 03: Production Scrap Containment Engine

## Goal
Implement the **Production Scrap Containment Engine** (`CNTN-01..04`) that identifies the last-known-good cycle before drift started, bounds the suspect cycle window, tracks key milestone cycles (drift, intervention, recovery, release), and partitions production batches into clear operational dispositions (`RELEASED_PRE_DRIFT`, `QUARANTINE_INSPECT`, `RELEASED_POST_RECOVERY`).

## Requirements Addressed
- `CNTN-01`: System identifies last-known-good cycle.
- `CNTN-02`: System identifies suspect window (potentially affected cycles between drift detection and recovery).
- `CNTN-03`: System identifies intervention cycle, recovery cycle, and release cycle.
- `CNTN-04`: System answers "which production should we inspect, quarantine, or release?".

## Proposed Files
- `src/process_guardian/containment/schemas.py`: Data models for disposition types, containment windows, and batch disposition reports.
- `src/process_guardian/containment/engine.py`: `ScrapContainmentEngine` tracking milestone cycles, computing suspect windows, and partitioning cycle dispositions.
- `src/process_guardian/containment/__init__.py`: Public package exports.
- `tests/test_scrap_containment.py`: Unit tests validating last-known-good cycle discovery, suspect window calculations, milestone tracking, and batch disposition partitioning.
