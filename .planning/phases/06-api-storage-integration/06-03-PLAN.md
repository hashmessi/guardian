# Phase 6 Plan 03: Quality, Intervention & Recovery/Containment API Endpoints

## Goal
Implement the REST endpoints for Quality Risk (`API-03`), Intervention Evaluation & Application (`API-04`), and Recovery Verification & Scrap Containment (`API-05`).

## Requirements Addressed
- `API-03`: Quality endpoints: `GET /api/quality/risk`, `GET /api/quality/contract`.
- `API-04`: Intervention endpoints: `POST /api/interventions/simulate`, `GET /api/interventions/recommendation`, `POST /api/interventions/apply-demo`, `GET /api/interventions/history`.
- `API-05`: Recovery/containment endpoints: `GET /api/recovery/status`, `GET /api/containment/window`, `POST /api/containment/release`.

## Proposed Files
- `src/process_guardian/api/routes/quality.py`: Route handlers for real-time quality risk probabilities, confidence, risk states, and quality contract tolerances.
- `src/process_guardian/api/routes/interventions.py`: Route handlers for candidate simulation, 7-field recommendation contract, demo intervention application, and historical lookup.
- `src/process_guardian/api/routes/recovery.py`: Route handlers for recovery status, containment window queries, and batch release authorization.
- `tests/test_api_interventions_recovery.py`: Unit and integration tests validating quality, intervention, and recovery endpoints.
