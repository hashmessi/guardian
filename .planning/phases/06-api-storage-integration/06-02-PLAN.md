# Phase 6 Plan 02: FastAPI Core Service Layer & Ingestion + Process Endpoints

## Goal
Implement the FastAPI application core, dependency injection container, error handlers, and the Ingestion (`API-01`) and Process State (`API-02`) route handlers.

## Requirements Addressed
- `API-01`: FastAPI ingestion endpoints: `POST /api/cycles`, `POST /api/events`, `POST /api/checkpoints`.
- `API-02`: Process state endpoints: `GET /api/process/current`, `GET /api/process/fingerprint`, `GET /api/process/drift`.
- `STOR-01` & `STOR-02`: Integration with SQLite storage repository and unified event logging.

## Proposed Files
- `src/process_guardian/api/app.py`: FastAPI app factory, CORS middleware, lifespan events, exception handlers.
- `src/process_guardian/api/dependencies.py`: Dependency injection for orchestrator, storage repository, and simulator context.
- `src/process_guardian/api/schemas.py`: REST API request/response models.
- `src/process_guardian/api/routes/ingestion.py`: Route handlers for cycle ingestion (single/batch), event recording/injection, and state checkpointing.
- `src/process_guardian/api/routes/process.py`: Route handlers for current machine state, process fingerprint baselines, and drift sentinel status.
- `src/process_guardian/api/__init__.py`: API package exports.
- `tests/test_api_ingestion_process.py`: TestClient tests validating all ingestion and process state endpoints.
