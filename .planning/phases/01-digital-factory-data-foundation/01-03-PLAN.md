In `src/process_guardian/adapter/normalizer.py`, implement `TelemetryNormalizer`:
- Method `normalize_pressure(value: Optional[float], unit: str) -> Optional[float]`:
  - If `value is None`: return None.
  - If `unit.lower() == "psi"`: return `round(value / 14.50377, 2)` (bar).
  - If `unit.lower() == "mpa"`: return `round(value * 10.0, 2)` (bar).
  - Default "bar": return `round(value, 2)`.
- Method `normalize_temperature(value: Optional[float], unit: str) -> Optional[float]`:
  - If `value is None`: return None.
  - If `unit.lower() == "f"`: return `round((value - 32.0) * 5.0 / 9.0, 2)` (°C).
  - Default "c": return `round(value, 2)`.
- Method `generate_timestamp(raw_timestamp: Optional[Union[str, datetime, float]], cycle_index: int, base_time: Optional[datetime] = None) -> str`:
  - If valid ISO string or datetime provided, convert to UTC ISO 8601 string (`YYYY-MM-DDTHH:MM:SS.fffZ`).
  - If None, compute from `base_time` + `timedelta(seconds=cycle_index * 28.5)`.
- Class `SequenceTracker`:
  - Ensures strictly monotonic cycle indexing. If `raw.cycle_index` is missing or out-of-order, maintains an internal monotonic counter and logs warning.
  </action>

In `src/process_guardian/adapter/validator.py`, implement `TelemetryValidator`:
Define physical bounds dictionary `PHYSICAL_BOUNDS`:
- Barrel temperatures (z1-z5, nozzle): min 100.0°C, max 400.0°C
- Pressures (inj, peak, hold): min 0.0 bar, max 300.0 bar
- Timings (inj, hold, cool, cycle): min 0.1s, max 180.0s
- Part weight: min 50.0g, max 500.0g
- Material moisture: min 0.00%, max 2.0%

Define required signal list:
`REQUIRED_SIGNALS = ["barrel_temp_z1", "barrel_temp_z2", "barrel_temp_z3", "barrel_temp_z4", "barrel_temp_z5", "nozzle_temp", "injection_pressure", "peak_pressure", "hold_pressure", "injection_time", "hold_time", "cooling_time", "cycle_time", "part_weight", "material_moisture"]`

Method `validate(normalized_signals: Dict[str, Optional[float]]) -> Tuple[Dict[str, QualityFlag], bool]`:
- For each signal in `REQUIRED_SIGNALS`:
  - If value is None: tag `quality_flags[signal] = QualityFlag.MISSING_SIGNAL`.
  - Else if value < `PHYSICAL_BOUNDS[signal].min` or value > `PHYSICAL_BOUNDS[signal].max`: tag `quality_flags[signal] = QualityFlag.OUT_OF_BOUNDS`.
  - Else: tag `quality_flags[signal] = QualityFlag.VALID`.
- Return `(quality_flags, is_valid)`. `is_valid` is False if any required signal is `OUT_OF_BOUNDS` or `MISSING_SIGNAL`.
  </action>

  <acceptance_criteria>
    - `validator.py` contains `class TelemetryValidator:`

    - Does not throw exception on corrupt or missing signals
