In `src/process_guardian/simulator/regimes.py`, implement regime handlers:
Define class `RegimeConfig` and a registry/factory `get_regime_modifiers(regime: RegimeType, cycle_in_regime: int, rng: np.random.Generator) -> Dict[str, float]`.
Implement the 9 regimes:
1. `HEALTHY`: Pure zero-mean stationary Gaussian perturbations around nominal (std ~0.4°C for temps, ~0.8 bar for pressures, ~0.1s for times, ~0.08g for weight).
2. `THERMAL_DRIFT`: Cumulative linear drift on `barrel_temp_z3` (+0.2°C per cycle) and `nozzle_temp` (+0.1°C per cycle).
3. `PRESSURE_DRIFT`: Progressive drop in `injection_pressure` (-0.25 bar per cycle) and `peak_pressure` (-0.35 bar per cycle).
4. `MOISTURE_DRIFT`: Progressive increase in `material_moisture` (+0.005% per cycle from 0.02% up to 0.18%).
5. `CYCLE_INSTABILITY`: Erratic cooling water temperature fluctuations creating high-variance `cooling_time` (jitter ±2.5s) and `cycle_time` (jitter ±3.0s).
6. `COMBINED_DRIFT`: Both thermal drift (+0.2°C/cycle on z3) and moisture drift (+0.004%/cycle).
7. `SENSOR_NOISE`: Zero drift in process mean, but 5× higher standard deviation on `barrel_temp_z3` (±2.5°C jitter) and `injection_pressure` (±4.0 bar jitter) to simulate noisy thermocouple/transducer without physical melt shift.
8. `RECOVERY`: Exponential decay back from drifted state toward nominal parameters: `val = nominal + (drift_val - nominal) * exp(-cycle_in_recovery / 4.0)`.
9. `UNSEEN_DRIFT`: Sinusoidal thermal oscillation on zone 3 (`amplitude = 3.5°C`, `period = 12 cycles`) simulating temperature controller PID hunting.

  - Initializes `self.rng = np.random.default_rng(seed)`
  - Initializes `self.current_cycle = 0`

- Method `reset(self, new_seed: Optional[int] = None) -> None`:
  - If `new_seed` is provided, updates `self.seed = new_seed`.
  - Re-instantiates `self.rng = np.random.default_rng(self.seed)`.

  - Applies process noise and clamps physical limits.
  - Computes `RawCycleTelemetry` record, appends to `self.history`, and returns it.

  - Generates `n` sequential cycles and returns the list.
