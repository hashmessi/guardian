# Phase 3 Plan 03: Root Cause Attribution Engine & Honest Evidence Generator

## Goal
Implement the **Root Cause Evidence Engine** that attributes quality risk across process subsystems, normalizes contributions to strictly 100%, generates empirical supporting evidence, and enforces honest epistemics (ROOT-01, ROOT-02, ROOT-03).

## Requirements Addressed
- `ROOT-01`: System provides ranked likely contributors with percentage contribution (e.g., Temperature 68%, Pressure 21%, Cycle 8%, Other 3%) summing strictly to 100%.
- `ROOT-02`: System provides supporting evidence for each contributor (variance changes, distribution shifts, similar past events).
- `ROOT-03`: System uses honest language: "likely contributor", "evidence", "modeled effect", "confidence" — never "guaranteed cause" or "proven causal effect".

## Proposed Files
- `src/process_guardian/root_cause/analyzer.py`: `RootCauseAnalyzer` computing feature attribution, category rollup, and percentage normalization.
- `src/process_guardian/root_cause/evidence.py`: `EvidenceGenerator` formatting distribution shifts, trend slopes, and baseline z-scores with strict epistemic honesty linting.
- `src/process_guardian/root_cause/schemas.py`: `RootCauseReport`, `ContributorItem`, `SubsystemAttribution`.
- `tests/test_root_cause.py`: Unit tests for percentage normalization ($\sum \equiv 100.0\%$), evidence formatting, and banned phrase rejection.
