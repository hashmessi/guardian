# Phase 3 Plan 01: Quality Contract Definition & Feature Engineering Pipeline

## Goal
Implement the **Quality Contract** schema and the **Temporal Feature Engineering Pipeline** that extracts 45+ statistical, temporal, and physical interaction features per cycle from telemetry and process fingerprints (QRSK-02, QRSK-03).

## Requirements Addressed
- `QRSK-02`: System uses temporal feature engineering (current value, rolling mean/std, trend/slope, delta from fingerprint, lag features, interaction features, process-phase features, material moisture, machine context).
- `QRSK-03`: System evaluates risk against a defined Quality Contract (part-specific targets and tolerances).

## Proposed Files
- `src/process_guardian/quality/contract.py`: `QualityContract`, `ToleranceRange`, `ContractEvaluationResult`.
- `src/process_guardian/quality/features.py`: `TemporalFeatureExtractor` extracting rolling, lag, delta, and coupled physics features.
- `tests/test_quality_features.py`: Unit tests for feature extraction and contract tolerance evaluation.

## Verification
- Run `pytest tests/test_quality_features.py -v`.
