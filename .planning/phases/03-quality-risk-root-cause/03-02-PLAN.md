# Phase 3 Plan 02: Calibrated Quality Risk Predictor

## Goal
Implement the **Calibrated Quality Risk Model** using `XGBClassifier` and probability calibration to output well-calibrated defect risk probabilities $P(\text{Defect}) \in [0.0, 1.0]$, confidence metrics, and categorical risk states (`LOW`, `MEDIUM`, `HIGH`) mapping to operator modes (QRSK-01, QRSK-04).

## Requirements Addressed
- `QRSK-01`: System produces calibrated quality risk probability (0-1) with confidence score using XGBoost/LightGBM.
- `QRSK-04`: System classifies risk state (LOW / MEDIUM / HIGH) with corresponding operator modes.

## Proposed Files
- `src/process_guardian/quality/model.py`: `QualityRiskModel` with training, inference, Platt scaling / calibration, and confidence estimation.
- `src/process_guardian/quality/schemas.py`: `QualityRiskOutput`, `RiskState` (`LOW`, `MEDIUM`, `HIGH`), `OperatorMode`.
- `tests/test_quality_risk.py`: Unit tests for calibrated probability distribution, confidence bounds, and state transitions.

## Verification
- Run `pytest tests/test_quality_risk.py -v`.
