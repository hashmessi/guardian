# Plan 12-02: Counterfactual Comparison REST API Endpoints (CRPL-01, CRPL-02)

## Objective
Expose the counterfactual replay comparison via REST API endpoints in `src/process_guardian/api/routes/counterfactual.py` and register in the FastAPI application.

## Scope
- Endpoints:
  - `GET /api/counterfactual/compare`: Return comprehensive comparison between Guardian OFF and Guardian ON.
  - `POST /api/counterfactual/replay`: Execute customized replay with optional parameters (horizon cycles, drift regime).
- App integration:
  - Register route in `src/process_guardian/api/app.py`.
  - Add counterfactual engine instance or factory in `src/process_guardian/api/dependencies.py`.
- Tests: `tests/test_counterfactual_api.py`
  - Test `GET /api/counterfactual/compare` returns 200 with both runs, delta KPIs, and stream points.
  - Test `POST /api/counterfactual/replay` returns 200 with updated comparison.
  - Test suspect lot reduction $\ge 75\%$ in API response.
