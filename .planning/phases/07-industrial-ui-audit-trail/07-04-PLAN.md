### Task 1: Add CORS middleware to FastAPI

<action>
Read src/process_guardian/api/main.py to find the FastAPI app instance and existing middleware.

Add CORS middleware to allow Vite dev server calls:

  from fastapi.middleware.cors import CORSMiddleware

  app.add_middleware(
      CORSMiddleware,
      allow_origins=["http://localhost:5173", "http://127.0.0.1:5173"],
      allow_credentials=True,
      allow_methods=["*"],
      allow_headers=["*"],
  )

Place the add_middleware call BEFORE any router includes.
Do not remove any existing middleware.
</action>

</acceptance_criteria>
