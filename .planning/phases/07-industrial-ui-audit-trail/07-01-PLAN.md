### Task 6: Build AppShell.jsx -- three-zone header

<action>
Create frontend/src/components/AppShell.jsx.

Zone 1 -- Brand bar (parchment background):
  Left: "PROCESS GUARDIAN" wordmark (weight:540, uppercase, charcoal) + "Injection Process Intelligence" subtitle (12px, stone gray)
  Right: animated pulse dot (alternates active/inactive every 1s via setInterval) + "SIMULATION . 2s STREAM" label (12px, stone, uppercase)
  NOTE: Use "SIMULATION" not "live" -- never imply real factory connection.

Zone 2 -- Scenario + Machine context (parchment, hairline border):
  "DEMO . THERMAL DRIFT" -- STATIC text (wine color, weight:540, uppercase) -- this is the scenario narrative
  "HTF-200 . GMB-48A . Automotive Bracket . R-12 . Cycle #437" -- cycle number DYNAMIC from /api/process/current

Zone 3 -- PS02 Hero Stats (4 white cards in CSS grid, no box-shadow):
  Cards: TEMP (barrel_temperature from processData.signals), PRESSURE (injection_pressure),
  MOISTURE (material_moisture), QUALITY RISK (risk_probability*100 from riskData)
  Each card: label (12px stone gray uppercase), value (32px weight:600 charcoal tabular-nums), status pill
  Pill logic: drift signals from driftData.contributing_signals -> wine pill "DRIFT"; else lagoon pill "NORMAL"
  Risk pill: HIGH->wine, MEDIUM->violet, LOW->lagoon

Zone 4 -- TabStrip component (imported from ./TabStrip)

usePolling endpoints:
  /api/process/current -- processData (cycle_id, signals)
  /api/quality/risk -- riskData (risk_probability or quality_risk_pct, risk_state)
  /api/process/drift -- driftData (is_drifting, contributing_signals)
</action>
