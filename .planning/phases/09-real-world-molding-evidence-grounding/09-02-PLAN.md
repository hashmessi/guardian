# Plan 09-02: Automated Grounding Benchmark Report & SPC Failure Proof (EVID-02)

## Objective
Build the automated grounding benchmark report engine comparing Process Guardian's digital factory and drift detection against published 2026 industrial automotive molding findings, proving that Process Guardian catches failure modes where conventional factory SPC fails.

## Target Requirements
- **EVID-02**: Grounding benchmark report comparing simulator drift dynamics against real industrial automotive study findings (non-linear moisture threshold 3% vs 22%, within-machine-limits visual scrap).

## Proposed Changes
1. Create `src/process_guardian/evidence/grounding_report.py`:
   - `GroundingBenchmarkEngine`:
     - Compares Process Guardian's Drift Sentinel against conventional single-variable threshold alarms ($\pm 3\sigma$ control chart limits).
     - Test Case 1: **2026 Industrial Automotive Component Study Reproduction (1,524 parts / 254 cycles)**:
       - Shows how 100% of cycles passed machine parameter tolerance limits, yet downstream camera found 8.3% defective parts.
       - Proves Process Guardian's multi-variable Hotelling $T^2$ + CUSUM detected the drift at cycle 18 (9 cycles before visual defects occurred).
     - Test Case 2: **Non-Linear Resin Moisture Sensitivity**:
       - Models the empirical non-linear response: 0.05%-0.15% moisture yields 2.8% defect rate, while >0.20% moisture yields 23.4% defect rate due to hydrolytic degradation and splay.
       - Validates that Process Guardian's Quality Risk model captures this non-linear cliff rather than a naive linear assumption.
     - Test Case 3: **Tier-1 Supplier 1-Month Scrap Reduction Case**:
       - Compares the 2025 Tier-1 case (reducing scrap from 20% to near 0% through constrained parameter optimization) to Process Guardian's surrogate optimization loop.
   - CLI runner: `python -m process_guardian.evidence.grounding_report` outputting a structured JSON artifact `.planning/grounding_benchmark_report.json` and a readable ASCII scorecard.
2. Create `tests/test_grounding_report.py`:
   - Verify report generation runs cleanly.
   - Verify non-linear moisture threshold metrics and in-limits detection lead time.
   - Verify output JSON schema.
