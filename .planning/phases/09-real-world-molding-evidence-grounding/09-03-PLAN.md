# Plan 09-03: 4-Level Epistemic Evidence API, UI Evidence Modal & Verification (EVID-03)

## Objective
Enforce strict 4-level epistemic evidence labeling across the entire system. Build the FastAPI evidence endpoints (`/api/evidence/*`), build the frontend `EvidenceModal` component with interactive Level-1 to Level-4 cards and external dataset correlation tables, and verify end-to-end integration.

## Target Requirements
- **EVID-03**: Strict 4-level epistemic evidence labeling across all UI elements and API responses (Level 1: Challenge, Level 2: External Measured, Level 3: Software Invariant, Level 4: Controlled Counterfactual).

## Proposed Changes
1. Create `src/process_guardian/api/routes/evidence.py`:
   - Endpoint: `GET /api/evidence/levels`: Complete 4-level taxonomy, definitions, and verification proofs.
   - Endpoint: `GET /api/evidence/external-benchmark`: Real measured dataset summary (564 parts, PP/ABS), feature correlation matrix, and machine-limits failure rate.
   - Endpoint: `GET /api/evidence/grounding-report`: Automated grounding evaluation comparing digital factory drift against the 2026 automotive study.
2. Register evidence router in `src/process_guardian/api/app.py`.
3. Create `frontend/src/components/EvidenceModal.jsx` and `frontend/src/components/EvidenceModal.css`:
   - Interactive evidence viewer accessible via an `Evidence Stack` button in `AppShell` brand bar.
   - Tab 1: **4-Level Evidence Chain** (Level 1 Challenge, Level 2 External Measured, Level 3 Invariants, Level 4 Replay).
   - Tab 2: **Measured Molding Benchmark** (SKZ/Fraunhofer 564-part data, feature correlations, OK/NOK breakdown).
   - Tab 3: **Conventional SPC Failure vs Guardian Lead Time** (reproducing 2026 automotive study findings).
4. Update `frontend/src/components/AppShell.jsx` to render the `EvidenceModal` trigger with epistemic badges.
5. Create `tests/test_epistemic_evidence_api.py`:
   - Test all 3 evidence endpoints over HTTP.
   - Verify epistemic level tags match schemas.
   - Verify CORS and response times.
