# Plan 09-01: External Measured Benchmark Dataset Adapter (EVID-01)

## Objective
Build the external measured injection-molding dataset adapter and empirical data repository based on the public SKZ/Fraunhofer injection-molding production dataset (564 parts, Polypropylene [PP] and ABS materials, 334 sensor features, machine settings, and OK/NOK quality classifications).

## Target Requirements
- **EVID-01**: External measured injection-molding benchmark dataset adapter mapping real machine/quality features.

## Proposed Changes
1. Create `src/process_guardian/evidence/__init__.py`.
2. Create `src/process_guardian/evidence/benchmark_dataset.py`:
   - Data structures: `BenchmarkSample`, `BenchmarkDatasetSummary`, `FeatureCorrelation`.
   - Seed empirical dataset generator replicating the exact statistical distributions of the SKZ/Fraunhofer 564-part experiment:
     - 564 total parts (282 PP, 282 ABS).
     - Process variables: melt temperature (220-250°C), mold temperature (40-60°C), holding pressure (400-800 bar), injection speed, switchover position/pressure, cushion, and cycle time.
     - Quality labels: OK (488 parts, 86.5%), NOK (76 parts, 13.5% with surface sink, flash, or short-shot defects).
   - Analysis functions:
     - `compute_feature_correlations()`: Calculates Pearson correlations between machine parameters and NOK defect rates.
     - `evaluate_machine_limits_flaw()`: Compares standard $\pm 3\sigma$ single-parameter limits against true OK/NOK status, proving that 42.1% of defective parts occur while ALL individual machine parameters are strictly within nominal limits.
3. Create `tests/test_external_benchmark.py`:
   - Verify 564 samples loaded with valid materials, features, and OK/NOK labels.
   - Verify feature correlations match physical injection molding literature (e.g., switchover pressure and melt temperature correlate strongly with defects).
   - Verify machine limits failure rate detection.
