# Plan 13.2: Counterfactual Dual Replay & Operational Scorecard Engine

## Goal
Build the deterministic counterfactual dual replay engine (Guardian OFF vs Guardian ON) across scenarios, implement the 7-pillar objective evidence scorecard evaluator, and construct the batch validation suite runner.

## Requirements
- Deterministic dual simulation: identical seed, initial conditions, and disturbance timeline for Guardian OFF vs Guardian ON.
- 7-pillar objective scorecard evaluating:
  1. Early Drift Detection
  2. Root Cause Attribution
  3. Constrained Intervention
  4. Recovery Verification
  5. Scrap Containment Quarantine
  6. Physical QC Release Gate
  7. Counterfactual Causality Proof
- Batch runner executing all 10 scenarios and aggregating industrial reliability metrics.
- REST API routes for listing, fetching, selecting, running scenarios, and compiling validation suite reports.

## Tasks
1. Implement `ScenarioScorecardEvaluator` asserting 7 pillars against `ExpectedOutcome`.
2. Implement `ScenarioRunner` dual replay loop with CoPQ calculations.
3. Implement `OperationalValidationSuiteRunner` compiling `OperationalValidationSuiteReport`.
4. Expose REST endpoints in `process_guardian/api/routes/scenarios.py` and register in service container.
5. Create comprehensive unit and API integration tests.
