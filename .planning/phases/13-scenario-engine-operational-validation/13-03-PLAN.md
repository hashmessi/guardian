# Plan 13.3: Frontend Scenario Selector, Evidence Scorecard & Validation Suite

## Goal
Integrate scenario controls and evidence modals into the Process Guardian industrial UI shell, providing automotive evaluators with instant scenario switching, narrative timeline tracking, the 7-pillar objective evidence scorecard, and the 10-scenario validation suite report.

## Requirements
- Scenario Selector dropdown in header context zone allowing switching between 6 primary hero scenarios.
- Scenario Timeline Bar rendered above the active screen showing cycle horizon, seed, active cycle, and narrative phase milestones.
- Scenario Result Scorecard Modal displaying 7-pillar checklist with pass/fail badges, status codes, metrics, and honest simulation disclaimers.
- 10-Scenario Operational Validation Suite Modal displaying 10/10 verified status, aggregate reliability metrics, and per-scenario cards with instant jump-to-scenario.
- Clean Vite build and full unit/E2E test pass.

## Tasks
1. Create `ScenarioTimelineBar.jsx` and `.css`.
2. Create `ScenarioScorecardModal.jsx` and `.css`.
3. Create `ValidationSuiteModal.jsx` and `.css`.
4. Integrate components and state into `AppShell.jsx` and `useApi.js`.
5. Verify Vite production build and regression test suite.
