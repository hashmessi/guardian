# Plan 10-03: REST API Endpoints, UI Hero Card & End-to-End Verification (ECON-01, ECON-02)

## Objective
Expose the decision economics and parametric CoPQ through REST API endpoints, integrate dynamic calculation into the demo savings endpoint, create the frontend Economics Hero Card and Parametric CoPQ Drawer, and execute full end-to-end test verification.

## Scope
- Backend API: `src/process_guardian/api/routes/economics.py`

  - `GET /api/economics/copq`: Get current itemized CoPQ breakdown per part.
  - `GET /api/economics/decision-value`: Get real-time Cost of Waiting vs Cost of Acting evaluation.

  - Update `src/process_guardian/api/routes/demo.py` to use parametric CoPQ for avoided scrap value.
