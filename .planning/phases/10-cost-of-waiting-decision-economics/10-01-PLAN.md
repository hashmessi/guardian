# Plan 10-01: Parametric Cost of Poor Quality (CoPQ) Engine (ECON-01)

## Objective
Build the parametric Cost of Poor Quality (CoPQ) calculation engine and Pydantic schemas in `src/process_guardian/economics/`. Replace flat ₹450 assumption with granular shop-floor molding cost components: virgin resin weight, runner scrap fraction, regrind credit, machine hourly burden rate, cycle time, energy power consumption, kWh electricity tariff, secondary sorting labor, and downstream OEM penalty risk.

## Scope
- Module: `src/process_guardian/economics/models.py`
  - Define `CoPQParameters` with validation constraints and Tier-2/Tier-3 automotive defaults.
  - Define `CoPQBreakdown` with itemized and aggregate currency amounts.
- Module: `src/process_guardian/economics/engine.py`
  - Implement `CoPQCalculator` computing exact mathematical breakdowns.
- Unit Tests: `tests/test_copq_model.py`
  - Test default calculations against known numerical baselines.
  - Test parameter override behaviors, edge cases (zero sorting, zero regrind, heavy runner).

## Verification
- Run `pytest tests/test_copq_model.py` and confirm all test cases pass.
