# Phase 8 Plan 01: 10-Scenario Validation Suite & CLI Scorecard Runner

## Goal
Implement the comprehensive validation scenario catalog covering all 10 operational regimes and edge cases (`DEMO-01`), build the automated behavioral test suite verifying deterministic system responses, and provide a standalone CLI runner that prints an executive scorecard and exports a machine-readable JSON artifact.

## Requirements Addressed
- `DEMO-01`: Complete 10-step demo story and 10 validation scenarios:
  1. Healthy Baseline (false-positive avoidance)
  2. Thermal Drift (full closed loop: detect → diagnose → intervene → verify → contain)
  3. Pressure Drift (pressure-specific intervention)
  4. Moisture Drift (material check / drying cycle escalation)
  5. Sensor Noise (noise robustness)
  6. Combined Drift (multi-signal root-cause attribution)
  7. Sustained Recovery (3-cycle cooling window verification)
  8. Missing Signal (graceful degradation)
  9. Unseen Drift (mandatory ABSTAIN gate)
  10. Sudden Shift (fast-response quarantine)

## Proposed Files
- `src/process_guardian/validation/scenarios.py`: Scenario definitions and builders for all 10 validation regimes with precise behavioral assertions.
- `src/process_guardian/validation/runner.py`: Validation suite execution engine that executes scenarios against the orchestrator and produces structured results.
- `src/process_guardian/validation/__main__.py`: CLI entry point (`python -m process_guardian.validation`) rendering a clean ANSI terminal scorecard and writing `.planning/validation_report.json`.
- `tests/test_validation_scenarios_suite.py`: Automated pytest test suite executing all 10 scenarios with strict behavioral assertions.

## Verification
- Run `python -m process_guardian.validation` and verify all 10 scenarios PASS with formatted terminal table and JSON output.
- Run `pytest tests/test_validation_scenarios_suite.py -v` ensuring 10/10 tests green.
