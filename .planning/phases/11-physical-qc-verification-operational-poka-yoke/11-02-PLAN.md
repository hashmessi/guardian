# Plan 11-02: PS02 Shop-Floor Operational Checkpoints Engine (QCHK-02)

## Objective
Implement the 3 mandatory PS02 shop-floor operational checkpoints in `src/process_guardian/quality/operational_checkpoints.py`:
1. Recipe Verification Lock: verify active machine parameters against signed recipe tolerances (`R-12`).
2. Resin Moisture Batch Sign-Off: enforce material hopper moisture <= 0.15% with recorded inspector ID.
3. Mold-Release Spray Interval Tracking: track cycle interval since last mold-release spray application (scheduled every 50 cycles).

## Scope
- Module: `src/process_guardian/quality/operational_checkpoints.py`
  - Define `RecipeVerificationCheckpoint`: compares zone temperatures, pressures, and cooling times against master recipe.
  - Define `ResinMoistureCheckpoint`: checks material moisture against 0.15% maximum threshold.
  - Define `MoldReleaseSprayCheckpoint`: tracks `last_spray_cycle`, `cycles_since_spray`, and max interval.
  - Define `OperationalCheckpointsReport`: unified evaluation payload with individual statuses and `overall_clearance: bool`.
  - Implement `OperationalCheckpointsEvaluator`.
- Unit Tests: `tests/test_operational_checkpoints.py`
  - Test recipe mismatch triggers `UNAUTHORIZED_OVERRIDE` and locks clearance.
  - Test moisture > 0.15% (e.g. 0.22%) triggers `BLOCKED_DRYING_REQUIRED`.
  - Test spray overdue (> 60 cycles) flags `SPRAY_OVERDUE`.
  - Test all nominal yields `overall_clearance = True`.
