# Phase 4 Plan 04: End-to-End Demo Benchmark & Pipeline Integration

## Goal
Integrate the Candidate Generator, Constraint Checker, Surrogate Model, Cost Optimizer, and Recommendation Engine into a unified `InterventionEngine` pipeline (`src/process_guardian/intervention/pipeline.py`), export the public package API in `__init__.py`, and benchmark the full decision loop on the primary demo scenario and multi-regime simulations (INTV-01..05, RCMD-01..03).

## Requirements Addressed
- Full Phase 4 integration and benchmark verification across all 8 requirements (`INTV-01`, `INTV-02`, `INTV-03`, `INTV-04`, `INTV-05`, `RCMD-01`, `RCMD-02`, `RCMD-03`).

## Proposed Files
- `src/process_guardian/intervention/pipeline.py`: `InterventionEngine` exposing a unified method `evaluate(record, fingerprint, risk_output, drift_output, root_cause_report) -> Tuple[InterventionRecommendation, InterventionComparisonTable]`.
- `src/process_guardian/intervention/__init__.py`: Public package exports.
- `tests/test_intervention_demo_benchmark.py`: End-to-end benchmark test verifying:
  - Primary demo scenario progression: healthy baseline $\to$ thermal drift $\to$ drift sentinel $\to$ quality risk high $\to$ root cause points to Zone 3 $\to$ intervention engine recommends $A_1$ (temperature reduction) $\to$ validates 7 fields, table, expected risk reduction, and recovery criteria.
  - Multi-regime behavior: Pressure drift recommendation, moisture drift recommendation, low confidence ABSTAIN gate.
