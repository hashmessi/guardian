# Phase 4 Plan 01: Candidate Action Generation & Multi-Constraint Boundary Checks

## Goal
Implement the candidate action generator producing at least 5 operational actions ($A_0-A_4$) and the multi-constraint verification engine enforcing machine safety, recipe limits, fingerprint operating envelope, single-step limits, and drift-opposing direction (INTV-01, INTV-02).

## Requirements Addressed
- `INTV-01`: System evaluates at least 4 candidate actions (A0: continue monitoring, A1: temperature adjustment, A2: pressure adjustment, A3: cycle/process adjustment, A4: material inspection/check).
- `INTV-02`: Every candidate action is checked against operating envelope, recipe limits, max permitted parameter delta, machine safety bounds, intervention policy.

## Proposed Files
- `src/process_guardian/intervention/schemas.py`: Data models for candidate actions, boundary definitions, constraint results, and action evaluations.
- `src/process_guardian/intervention/candidates.py`: `CandidateGenerator` generating actions $A_0 \dots A_4$ based on drift state, and `ConstraintChecker` enforcing multi-level boundary compliance.
- `tests/test_intervention_candidates.py`: Unit tests validating candidate action generation, parameter delta bounds, and multi-constraint enforcement.

## Verification
- Run `pytest tests/test_intervention_candidates.py -v`.
