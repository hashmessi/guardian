# Phase 4 Plan 03: 7-Field Recommendation Contract, Operator Modes & Mandatory ABSTAIN Safety Gate

## Goal
Implement the **Structured Recommendation Engine** generating the 7-field recommendation contract (`ACTION`, `WHY`, `EVIDENCE`, `EXPECTED EFFECT`, `CONFIDENCE`, `OPERATING LIMIT`, `RECOVERY CHECK`), mapping the 3 operator modes (`NORMAL_MONITORING`, `REQUEST_QC_SAMPLE`, `RECOMMEND_ACTION`, `ABSTAIN_AND_MONITOR`), and enforcing the mandatory **ABSTAIN** safety gate when confidence $< 0.65$ or all actions are infeasible (RCMD-01, RCMD-02, RCMD-03).

## Requirements Addressed
- `RCMD-01`: Every recommendation contains: ACTION, WHY, EVIDENCE, EXPECTED EFFECT, CONFIDENCE, OPERATING LIMIT, RECOVERY CHECK.
- `RCMD-02`: System supports 3 operator modes — HIGH CONFIDENCE → recommend action; MEDIUM → request additional QC sample; LOW → ABSTAIN + monitor.
- `RCMD-03`: ABSTAIN is a product feature — system must refuse to act when confidence is low.

## Proposed Files
- `src/process_guardian/intervention/recommendation.py`: `RecommendationEngine` creating `InterventionRecommendation` complying with the 7-field contract, operator modes, epistemic honesty linting, and mandatory ABSTAIN gate.
- `tests/test_recommendation.py`: Unit tests validating all 7 fields, operator mode routing, low-confidence ABSTAIN triggers, and banned dogmatic phrase rejection.
