# Phase 4 Plan 02: Surrogate Response Surface Risk Modeling & Cost-Disruption Optimization

## Goal
Implement the coupled-physics **Surrogate Response Surface Model** that estimates post-intervention cycle state and defect risk $\hat{P}_{\text{risk}}(A_i)$ (INTV-03), the **Constrained Cost-Disruption Optimizer** minimizing $J(A_i) = \hat{P}_{\text{risk}}(A_i) + \lambda C(A_i) + \mu D(A_i)$ (INTV-04), and generate the structured **Candidate Action Comparison Table** (INTV-05).

## Requirements Addressed
- `INTV-03`: System uses surrogate model (learned response surface / constrained regression) to estimate post-intervention quality risk for each candidate.
- `INTV-04`: System optimizes minimize(predicted_quality_risk + λ×intervention_cost + μ×process_disruption) subject to machine/recipe/envelope constraints.
- `INTV-05`: System outputs comparison table (Do nothing → X% risk, Pressure → Y% risk, Temperature → Z% risk, etc.) with recommended action.

## Proposed Files
- `src/process_guardian/intervention/surrogate.py`: `InterventionSurrogateModel` applying coupled polymer physics dynamics to estimate post-action telemetry and evaluating $\hat{P}_{\text{risk}}$ with `QualityRiskModel`.
- `src/process_guardian/intervention/optimizer.py`: `InterventionOptimizer` calculating cost, disruption, objective score $J$, ranking feasible candidates, and formatting the comparison table.
- `tests/test_intervention_optimizer.py`: Unit tests verifying surrogate physics coupling, risk reduction estimation, objective minimization, and comparison table integrity.
