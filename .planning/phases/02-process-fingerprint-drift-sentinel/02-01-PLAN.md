In `src/process_guardian/fingerprint/builder.py`, implement `FingerprintBuilder`:
- Method `fit(records: List[NormalizedCycleRecord], ridge_epsilon: float = 1e-4) -> ProcessFingerprint`:
  1. Validates `len(records) >= 15`. Asserts context consistency across records.
  2. Extracts feature matrix for signals:
     `FEATURE_SIGNALS = ["barrel_temp_z1", "barrel_temp_z2", "barrel_temp_z3", "barrel_temp_z4", "barrel_temp_z5", "nozzle_temp", "injection_pressure", "peak_pressure", "hold_pressure", "injection_time", "hold_time", "cooling_time", "cycle_time", "part_weight", "material_moisture"]`.
  3. For each signal, computes `SignalStats`:
     - mean, std (ddof=1), min, max, 1st and 99th percentiles using `np.percentile`, IQR ($p_{75} - p_{25}$).
     - `OperatingEnvelope`: lower_limit = $\mu - 3\sigma$, upper_limit = $\mu + 3\sigma$, warning_lower = $\mu - 2\sigma$, warning_upper = $\mu + 2\sigma$.
  4. Computes regularized inverse covariance matrix:
     - `X = np.array(...)` shape $(N, p)$
     - `cov = np.cov(X, rowvar=False)` shape $(p, p)$
     - Regularize: `cov_reg = cov + ridge_epsilon * np.eye(p)`
     - `inv_cov = np.linalg.pinv(cov_reg)`
  5. Assembles and returns `ProcessFingerprint` with context key `f"{ctx.machine_id}:{ctx.mold_id}:{ctx.part_id}:{ctx.recipe_id}:{ctx.recipe_version}"`.
  </action>
