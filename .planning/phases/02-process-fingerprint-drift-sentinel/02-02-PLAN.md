  <action>
Implement the 4 core statistical detector classes:
1. `src/process_guardian/sentinel/ewma.py`:
   - Class `EWMADetector`:
     - Parameters: `lambda_param: float = 0.15`, `L: float = 2.8`.
     - Maintains current smoothed values $z_{i,t}$ and sample count $t$.
     - Computes dynamic limits $UCL, LCL$ per signal based on fingerprint mean and std.
     - Method `update(signal_values: Dict[str, float]) -> Dict[str, Tuple[float, bool]]`: returns `{signal: (z_val, is_breached)}`.
     - Method `reset()`: resets state.
2. `src/process_guardian/sentinel/cusum.py`:
   - Class `CUSUMDetector`:
     - Parameters: $K = 0.5$, $H = 4.5$ (in standard deviation units).
     - Maintains $S^+$ and $S^-$ for each signal.
     - Method `update(signal_values: Dict[str, float]) -> Dict[str, Tuple[float, float, bool]]`: returns `{signal: (s_pos, s_neg, is_breached)}`.
     - Method `reset()`.
3. `src/process_guardian/sentinel/multivariate.py`:
   - Class `MultivariateDetector`:
     - Uses `mean_vector` and `inv_cov_matrix` from `ProcessFingerprint`.
     - Degrees of freedom $p = len(features)$. Threshold $T_{crit} = \sqrt{\chi^2_{0.99}(p)}$ (via scipy.stats.chi2 or lookup table $\approx 5.5$ for $p=15$).
     - Method `compute_distance(feature_vector: np.ndarray) -> Tuple[float, bool]`:
       $D_M = \sqrt{(\mathbf{x} - \boldsymbol{\mu})^T \mathbf{\Sigma}^{-1} (\mathbf{x} - \boldsymbol{\mu})}$. Returns $(D_M, D_M > T_{crit})$.
4. `src/process_guardian/sentinel/trend.py`:
   - Class `SlidingTrendDetector`:
     - Sliding window of last 15 cycles per signal.
     - Computes least-squares linear slope: $slope = \frac{\sum (t - \bar{t})(x - \bar{x})}{\sum (t - \bar{t})^2}$.
  </action>

<task type="auto">
  <name>Task 3: Implement DriftSentinel fusion engine with persistence gating</name>
  <files>src/process_guardian/sentinel/detector.py</files>

  <action>
In `src/process_guardian/sentinel/detector.py`, implement `DriftSentinel`:
- Constructor: `__init__(self, fingerprint: ProcessFingerprint, min_warmup_cycles: int = 10, persistence_required: int = 2)`
  - Initializes `EWMADetector`, `CUSUMDetector`, `MultivariateDetector`, `SlidingTrendDetector`.
  - Initializes state: `self.consecutive_drift_count = 0`, `self.cycle_count = 0`.
- Method `evaluate(record: NormalizedCycleRecord) -> DriftOutput`:
  1. Increments `self.cycle_count`.
  2. Updates all 4 detectors with current cycle telemetry.
  3. Checks individual breaches:
     - Any signal breaching EWMA?
     - Any signal breaching CUSUM?
     - Multivariate distance $D_M > T_{crit}$?
     - Any signal with absolute z-score $|z| > 2.8$?
  4. Instantaneous drift condition:
     - `instant_drift = ewma_breach or cusum_breach or multi_breach or (max_z > 3.0)`
  5. Persistence gating:
     - If `instant_drift`: `self.consecutive_drift_count += 1`
     - Else: `self.consecutive_drift_count = max(0, self.consecutive_drift_count - 1)`
     - Confirmed drift boolean: `is_drift = (self.consecutive_drift_count >= self.persistence_required) and (self.cycle_count >= self.min_warmup_cycles)`
  6. Severity scoring:
     - Continuous score in $[0.0, 1.0]$:
       $score = 0.5 \times \min(1.0, \frac{\max(|z|)}{5.0}) + 0.5 \times \min(1.0, \frac{D_M}{T_{crit} \times 1.5})$
       If not `is_drift`: clamp severity $< 0.35$. If `is_drift`: min severity $0.40$.
  7. Signal attribution ranking:
     - Ranks signals in descending order of absolute z-score $|z|$. Filters to signals with $|z| > 1.5$.
  8. Lead time estimation:
     - For top drifting signal with $|slope| > 0.02$:
       computes remaining cycles before reaching envelope limit:
       $cycles_{lead} = \max(1, \text{int}(|envelope - current| / |slope|))$.
  9. Returns populated `DriftOutput`.
- Method `reset()`: resets all internal detector states and counters.
  </action>
